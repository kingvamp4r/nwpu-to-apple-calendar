# v1.3.0 · 课表、考试与多人订阅

从一次性课表导出升级为统一面板：在自己的教务登录中读取课表或考试安排，下载 ICS，或同步到个人日历订阅。

## 本次新增

- 单一日历面板，主要入口为“同步到日历”和“添加订阅”；下载、复制链接、设置和使用说明收纳在展开区域。
- 考试信息提取与独立考试订阅，包括表格中隐藏的已结束记录。缺少完整考试时间时停止导出及上传。
- 浏览器手动上传及可选自动同步，课表与考试订阅分别添加到 Apple Calendar。
- 邀请制多人使用：十分钟一次性配对码、按用户隔离数据、每台设备独立上传密钥、设备撤销及用户停用。
- Debian/systemd 订阅服务、缓存校验及持久事件 UID；兼容原有个人订阅和上传配置。
- README 提供普通用户使用步骤、管理员命令及部署入口。

## 安装与升级

安装或更新附件 `nwpu-to-apple-calendar.user.js`，也可使用 README 中的安装入口。升级后刷新教务主页，已有配置保留。

新用户向管理员领取配对码，在“新设备配对”中完成绑定。管理员在服务目录执行：

```bash
.venv/bin/python accounts.py create-user '用户备注'
```

已有服务器先备份私有数据，再更新代码并重启服务。首次启动会登记原有 owner，保留原订阅路径及事件映射。完整说明见 README 与 deploy/README.md。

## 验证与边界

- 20 项 Python 测试通过，覆盖用户隔离、配对并发／过期／重放、设备撤销、旧配置迁移、隐私字段筛选及日历事件处理。
- JavaScript 语法检查通过；面板交互与配对流程已使用测试配置验证。
- 现有个人课表、考试订阅及原上传凭证已在部署环境验证兼容。
- 新用户依赖自己的浏览器访问相关页面才能更新数据；服务器不会代其登录教务。
- 考试没有稳定记录 ID，复杂同名多场考试需要核对，遗漏记录不会自动取消。
- Apple Calendar 按自身刷新机制更新，不能保证实时显示。

本版本不包含任何个人课表、教务会话、订阅令牌或上传密钥。服务器与插件安装源的默认服务地址为 cal.kingvamp.asia；自部署需按 README 修改域名配置。
